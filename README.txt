AVANÇO R3.2 — FORMAÇÕES VISUAIS EM LINHAS

1. ATIVIDADE 09
O núcleo "Monte o desenho do time" passa a representar os setores como linhas reais:
- 4-3-3: D4 + M3 + A3
- 4-4-2: D4 + M4 + A2
- 4-2-3-1: D4 + V2 + M3 + A1

Cada grupo mostra visualmente a quantidade de jogadores.
O jogador move a linha como um bloco.

2. AVALIAÇÃO
Sai a dependência de acertar três/quatro coordenadas exatas.
A leitura considera principalmente:
- ordem vertical das linhas;
- distância relativa entre setores;
- altura geral em faixas amplas;
- coerência lateral do desenho.

O resultado é apresentado como "Leitura da formação", não como precisão geométrica.

3. CORREÇÃO TÉCNICA
Grupos com 1 jogador agora são permitidos, necessário para A1 no 4-2-3-1.

4. SUPABASE
task_catalog.act09_quadro_formacoes atualizado para revisão 2.
Nenhuma migration foi necessária.

5. PEDAGOGIA
A pergunta-chave permanece:
"O que mudou entre as linhas deste desenho e do anterior?"
Não exigir memorização da formação.
